# L346-E Findings — /profile/2fa UI audit

**Date:** 2026-10-03
**Discovered by:** L346-E (2FA UI structural tests)
**Type:** A11y gaps (documented, not fixed — L346-E scope is tests)
**Severity:** LOW–MEDIUM (visual/assistive gaps; no functionality broken)

## Documented A11y gaps (not fixed in L346-E)

| # | Gap | Location | Severity | Suggested fix |
|---|-----|----------|----------|---------------|
| 1 | Status badge lacks `role="status"` / `aria-live` | `.badge` span | MEDIUM | Add `role="status" aria-live="polite"` |
| 2 | Message areas lack `aria-live="polite"` | `#enroll-msg`, `#disable-msg` | MEDIUM | Screen readers do not announce; add live region |
| 3 | OTP input lacks `autocomplete="one-time-code"` | `#enroll-code`, `#disable-code` | LOW | Enable OS autofill for OTP |
| 4 | 3 of 4 inputs lack `<label for="...">` | `#enroll-code`, `#disable-code`, recovery download button | LOW | Add explicit labels or `aria-label` |
| 5 | No `prefers-color-scheme` dark-mode rule | `<style>` | LOW | Add media query |
| 6 | `.text-xs` (#9ca3af on #f5f5f5) may fail WCAG AA contrast | `<style>` | MEDIUM | Verify ratio; darken if <4.5:1 |

## What L346-E did NOT do

## Follow-up

Register as a new GAP:
`GAP-L346E-2FA-A11Y — 2FA page a11y improvements (6 items)`

Recommended priority: **LOW** — item 6 (contrast) is the only one
that may fail WCAG AA; items 1–2 impact screen readers.

Recommended owner: design owner (items 1–2 touch user-facing state
announcements).

Recommended fix effort: **SMALL** (~30 minutes for all 6 items).
