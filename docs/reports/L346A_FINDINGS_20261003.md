# L346-A Findings — TelegramPublicationController::stop() bug

**Date:** 2026-10-03
**Discovered by:** L346-A (T19-T31 local subset test)
**Type:** Production bug (not fixed in L346-A scope — reported for follow-up)

## Bug

`app/Http/Controllers/Api/V1/TelegramPublicationController.php::stop()`
(lines 62-68) writes to columns that do not exist on the model:

    foreach ($publications as $pub) {
        if (in_array($pub->status, ['SENT', 'PENDING'])) {   // no 'status'
            $pub->status = 'STOPPED';                        // no 'status'
            $pub->stopped_at = now();                        // no 'stopped_at'
            $pub->save();
        }
    }

## Model reality

`app/Models/TelegramPublication.php`:

- Field name is `state`, not `status`
- No `stopped_at` column
- Canonical states: QUEUED, SENDING, POSTED, RETRY, UNCERTAIN,
  FAILED, SKIPPED, REMOVAL_PENDING, REMOVED
- `STOPPED` is NOT a canonical state — stop is intended to be
  a transition to `REMOVAL_PENDING` (removal workflow)

## Impact

- Stop endpoint returns 200 but does not actually stop anything
- Silent failure: Eloquent ignores unknown attributes on save
- `in_array(null, ['SENT','PENDING'])` is false — loop body never
  runs, so the endpoint is effectively a no-op
- Telegram publications continue to be delivered after "stop"

## Evidence

- Test `T19_T31LocalSubsetTest::test_t30_telegram_publication_model_uses_state_field`
  asserts `state` is fillable and `status`/`stopped_at` are not.
- Test `test_t30_stop_by_owner_returns_ok_or_empty` passes with 200
  because the controller returns success unconditionally.

## Recommended fix (NOT applied — out of L346-A scope)

Replace the block with a proper state transition:

    foreach ($publications as $pub) {
        if (in_array($pub->state, [
            TelegramPublication::STATE_QUEUED,
            TelegramPublication::STATE_SENDING,
            TelegramPublication::STATE_RETRY,
        ], true)) {
            $pub->state = TelegramPublication::STATE_REMOVAL_PENDING;
            $pub->save();
        }
    }

Requires a decision on which canonical state represents "stop":
- `REMOVAL_PENDING` (with a downstream removal job), or
- a new canonical `STOPPED` state (schema + constants + transitions)
