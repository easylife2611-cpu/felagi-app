## AI Resilience

**Problem (documented in L287 + L318):**
- `gemini-flash-latest` (.env default) returns HTTP 503 during demand spikes
- `gemini-2.5-flash` (config default) returns HTTP 404 (deprecated)

**Fix (L319):**
- Default model: `gemini-flash-lite-latest`
- Fallback list: `[gemini-flash-lite-latest, gemini-3-flash-preview]`
- `GeminiClient::post()` rotates on HTTP 503/404 only
- Return shape unchanged — callers unaffected
