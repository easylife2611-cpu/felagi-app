# L347-B — S023 Offer Unlock Reconnected

**Date:** 2026-10-03
**Commit:** `248f175`
**Type:** Production bug fix

## Summary

Frontend `doUnlock()` in `resources/views/offer-unlock.blade.php` was
disconnected from the fully-implemented backend
`OfferUnlockController@store`. It only showed a toast message.

## Fix

`doUnlock()` now POSTs to `/api/v1/offer-submissions` with `need_id`
in body, `X-CSRF-TOKEN` header, cookie auth. On 2xx shows
`featurePendingBody`; on error shows error message. Button disabled
during request.
