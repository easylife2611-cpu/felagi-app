# Data Breach Response Plan

**Legal Basis:** Proclamation 1321/2024, Art. 30
**Effective:** 2026-10-01
**Deadline:** 72 hours to ECA + affected users

## 1. Severity
| Level | Criteria | Response |
|---|---|---|
| P1 | Sensitive data, mass | Immediate |
| P2 | Personal data | under 24h |
| P3 | Low risk | under 72h |
| P4 | No PII | Log only |

## 2. Response Steps
1. Detect (0-1h) - Alert via monitoring
2. Contain (1-4h) - Isolate, revoke tokens
3. Assess (4-24h) - Scope, affected users
4. Notify ECA (24-72h) - Written notice
5. Notify users (72h) - If high risk
6. Review (7d) - Post-incident report

## 3. Notification Content
- Nature of breach
- Data categories affected
- Likely consequences
- Measures taken
- Contact: dpo@felagi.et

## 4. Roles
| Role | Responsibility |
|---|---|
| DPO | Authority notification |
| Security Lead | Containment |
| Legal | Regulatory |
| Comms | User notification |

## 5. Record Keeping
Breaches logged 7 years.
